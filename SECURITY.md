# Security Policy

## Reporting a security issue

Do not open a public issue containing credentials, access tokens, private keys, internal infrastructure details, or other sensitive information.

If you identify a security issue in this project, report it privately to the repository owner through an appropriate private channel.

## Sensitive-data policy

This repository is intended to be safe for public use. Contributions must not include real customer or employer data.

Before publishing logs or examples, remove:

- Credentials and secrets
- Tokens
- Certificates and private keys
- Tenant IDs
- Subscription IDs
- Private resource IDs
- Internal IP addresses
- Internal DNS names
- Personal information
